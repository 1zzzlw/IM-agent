# 人物系统资源

| 路径 | 用途 | 当前读取方式 |
| --- | --- | --- |
| `psychology/` | 人物评价所需的心理学研究摘要与工程使用边界 | `app/system_knowledge/loader.py` 读取 Markdown，加入 `appraise` 的内部上下文 |
| `storage/chroma/` | 人物记忆的持久化语义索引 | Chroma 客户端与记忆检索、重建流程使用 |
| `storage/runtime/` | 加密凭据、媒体等运行数据；可由环境变量指定其他位置 | 凭据与媒体服务使用 |

旧 `knowledge_base/` 是编程 Agent 的工程资料，已经退出人物链路并清理。不要把存储目录当作旧知识文档一起删除。

## 心理知识如何使用

`psychology/` 中有来源的文档是对原始研究的简短转述，记录作者、题名、年份、链接和适用边界，不保存整本书或论文副本。`行为判断参考.md` 保留为项目工程约束，与研究结论分别说明。

当前只有小规模上下文加载，还没有实现心理资料的分块、向量化与按场景检索。加载器按文件名排序读取前 4 个 Markdown，每份最多 6000 字符；现有 3 份均能加载。资料显著增加前，应先完善检索与来源引用，不能直接不断堆积文件。

知识辅助人物理解情境；状态、关系、经历来源和结果提交仍由程序维护。论文不能直接给出“收到这句话就增加多少好感度”的确定公式，现有记忆温度、成长阈值等也不是经过心理学验证的参数。人物判断不能据此对真实用户作临床诊断。
