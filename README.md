# Lumina-Agent · 微光

Lumina（微光），是在低谷与黑夜中为自己点亮的一束光。不刺眼，但足够温暖。

面向长期相处的个性化虚拟人物 Agent 项目。

主角色由对话、记忆和提取三个 Agent 协作，随机事件 Agent 推进角色的自主生活。人格、情绪、记忆、关系与自主行为是核心设计重点，多模态模块提供图片、语音与实时通话的感知和表达。

## AI 数据库初始化

完整脚本：[docs/sql/imagent_init.sql](docs/sql/imagent_init.sql)。在 MySQL 8.0.16+ 客户端选中项目配置使用的数据库，执行此脚本一次，即可建立完整的 25 张 `imagent_` 表。脚本与[设计文档](docs/设计文档.md)中的 DDL 保持一致，不需要重建旧 `ai_*` 表，也不删除普通 IM 数据。

模型配置标识统一为 UUID 字符串；兼容路径的底层使用新表。没有主角色时历史返回空列表；第一次接受消息时创建基础“微光”角色，后续保持同一世界。系统默认模型来自 `CHAT__LLM_MODEL`、`CHAT__LLM_BASE_URL`、`CHAT__LLM_API_KEY`，也可在客户端保存私有模型连接并选择使用。无需重建这 25 张表。

## 运行与检查

项目要求 Python 3.12 或更高版本，依赖声明在 `pyproject.toml`。

```bash
uv sync
uv run python main.py
```

应用启动仍沿用现有环境配置及数据库、Redis、Nacos 等初始化流程。完整启动需要对应服务与配置可用；本轮完成基础文字聊天，未将其标为完整人物机制。

```bash
uv run python -m unittest discover -s tests -p "test_*.py"
```

SSE 保活、配置校验与接口参数有普通回归。设置 `IMAGENT_TEST_MYSQL=1` 可运行独立测试库的完整对话验证；再设置 `IMAGENT_TEST_LIVE_MODEL=1` 可额外验证真实默认模型的两轮对话。数据库创建/清理范围及验证方法见[设计文档中的验证说明](docs/设计文档.md#83-怎样运行验证)。
